# مدرسه‌یار معلم — Android Native 2.2.1

> اصلاح مهم 2.2.1: مشکل «هیچ کارت کار نمی‌کند / بخش پیدا نشد» در WebViewهای قدیمی‌تر با Session Restore سازگار برطرف شده است. رابط وب قدیمی همچنان هرگز نمایش داده نمی‌شود.

# مدرسه‌یار معلم — Android 2.2.0 Native Only

این نسخه با یک قانون قطعی ساخته شده است: **رابط قدیمی سایت هیچ‌وقت به کاربر نمایش داده نمی‌شود.**

## تجربه کاربر

- Splash، Login، MFA، داشبورد، کلاس‌ها، پیام‌ها و منوها Native هستند.
- کلیک روی هر ماژول یک صفحه Android باز می‌کند.
- فرم‌ها، ورودی‌ها، انتخاب‌ها، چک‌باکس‌ها، جدول‌ها و دکمه‌های عملیاتی به کنترل‌های Android تبدیل می‌شوند.
- آپلود فایل با File Picker اندروید انجام می‌شود.
- اگر یک ماژول قابل تبدیل/دریافت نباشد، خطای Native نمایش داده می‌شود؛ هیچ fallback بصری به رابط قدیمی وجود ندارد.
- ورود اثرانگشتی و نشست رمزنگاری‌شده حفظ شده‌اند.

## معماری فعلی

بک‌اند موجود برای همه ماژول‌ها API مستقل مستندشده در سورس Android ندارد. برای اینکه عملیات فعلی سرور از بین نرود، `NativeBridgeActivity` موتور سامانه را **فقط در پس‌زمینه و نامرئی** اجرا می‌کند و وضعیت صفحه را به کنترل‌های Native تبدیل می‌کند. WebView اصلی همیشه `INVISIBLE` و `alpha=0` است.

این یعنی UI کاربر Android است، ولی تا زمانی که API رسمی همه ماژول‌ها استخراج/ارائه نشود، transport برخی عملیات از موتور موجود سامانه استفاده می‌کند.

## نسخه

- versionName: `2.2.0-native-only`
- versionCode: `9`
- minSdk: 23
- targetSdk: 35
- Kotlin + Jetpack Compose + Material 3

## Build

Workflow آماده در `.github/workflows/build-apk.yml` قرار دارد. در GitHub Actions گزینه **Build installable debug APK** را اجرا کنید. خروجی: `app/build/outputs/apk/debug/app-debug.apk`.
